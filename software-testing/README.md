# Software Testing Portfolio

This page brings together my practical work, technical articles, training, and webinar reports about software testing. My main interests are unit testing, API testing, end-to-end testing, test automation, security testing, and software quality.

## Practical Projects and Technical Articles

### [Discount System Unit Tests – Technical Documentation](https://github.com/jahanalem/LiliShop-backend-dotnet-test#discount-system-unit-tests--technical-documentation)

Technical documentation for 42 fast unit tests covering discount price rules and lifecycle workflows. The tests use xUnit, Moq, FluentAssertions, and mocked database and background services.

### [From Postman Tests to a Stronger Backend: The LiliShop API Testing Story](https://github.com/jahanalem/LinkedIn2GitHub/blob/main/0065_Postman_API_testing_and_backend_improvement.md)

A practical case study of a complete Postman suite for the LiliShop API. It shows how API tests found backend problems in status codes, security headers, validation, database rules, and cleanup.

### [CatchEleven Unit Tests](https://github.com/jahanalem/CatchEleven/tree/master/tests/CatchEleven.Tests)

xUnit tests for the card game's combination-selection rules. They verify scoring priorities, including diamond cards and the Jack rule for taking all table cards.

### [SmartSupervisorBot Service Tests](https://github.com/jahanalem/SmartSupervisorBot/blob/main/SmartSupervisorBot.Test.Core/BotServiceTests.cs)

Unit tests for Telegram bot services using xUnit and Moq. They cover group creation, deletion, language changes, invalid inputs, logging, and concurrent calls.

### [RectanglesCalculator Unit Tests](https://github.com/jahanalem/RectanglesCalculator/tree/main/Nineteen.Rectangle.Test)

Unit tests for geometric models, JSON file handling, and parallel rectangle processing. The suite checks points, lines, rectangles, and the main calculation workflow.

### [Cypress End-to-End Testing: A Complete Beginner's Guide with LiliShop](https://github.com/jahanalem/LinkedIn2GitHub/blob/main/0049_Cypress-Ent-to-End-Testing.md)

A step-by-step guide to building maintainable E2E tests for an Angular application. It covers stable selectors, fixtures, custom commands, network interception, assertions, and a CI-friendly structure.
